# Nimbus

A landing page for a pretend money app. Nimbus isn't a real company or a real bank, and the numbers, prices and reviews on the page are all made up. I built it to practice a darker, glassy style with a lot happening on one page.

Live version: https://areebamalik0.github.io/nimbus-app/

The first screen has a phone that tilts in 3D as you move your mouse, with a balance chart that draws itself on the screen. Around it are floating cards, and the main headline cycles through a few words. A soft glow follows your cursor across the page.

Further down there's a grid of feature cards, a three-step section, numbers that count up, a pricing section with a monthly and yearly switch that really changes the prices, a few sample testimonials and an FAQ.

The waitlist form checks that the email looks right, but it doesn't send or save anything.

Built with plain HTML, CSS and JavaScript. No frameworks. To run it, download the files and open index.html in your browser.
